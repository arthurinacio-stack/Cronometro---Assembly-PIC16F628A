# Cronômetro em Assembly — PIC16F628A

Projeto de um cronômetro desenvolvido em Assembly para o microcontrolador PIC16F628A.

## Sobre o projeto

O sistema funciona como um cronômetro de 00 a 99, utilizando dois displays de 7 segmentos multiplexados.

O acionamento e o controle do cronômetro são realizados por meio do microcontrolador PIC16F628A.

## Funcionalidades

- Contagem de 00 a 99;
- Exibição das unidades e dezenas em displays de 7 segmentos;
- Multiplexação dos displays;
- Utilização do Timer0 para controle da temporização;
- Desenvolvimento em Assembly.

## Tecnologias

- PIC16F628A
- Assembly
- MPLAB IDE
- MPASM
